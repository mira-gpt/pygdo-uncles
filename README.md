# pygdo-uncles

Collectible WeChall-player cards for PyGDO.

Cards carry Crypto, Stegano, Programming, Exploit, Math, and Info ratings.
Fresh players receive ten low-rating starter cards sampled from WeChall ranks
100–200. Use `$uncle <user>` to confront an online player; the loser stakes the
selected card. `$uncles` displays your collection.
